New Day Summary case

Writes a Day Summary from a made-up day with the live memory processing prompt. The Judge then answers each question from the Summary alone, and the case passes only if every answer matches.

Sample data

Key

The case’s stable name, e.g. guilt-and-job-worry. Runs and the terminal pick the case by it, so it can’t change later. Lowercase letters, numbers and hyphens; unique across all Evals.

guilt-and-job-worry

The day

The messages of one made-up day, in order. The memory processing step reads these to write the Day Summary.

Questions

What the Summary must be able to answer: the facts, the feelings, and what Zeph offered and how it landed. The Judge sees only the Summary, never the messages.

About this page

Every Eval case form has this shape: Key, then one panel per part of the case, each with a hint, repeated entries in inset groups with their own Remove, and an Add button under the last one. Editing a saved case drops the Key panel and the button reads “Save case”.
