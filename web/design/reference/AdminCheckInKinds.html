The kinds of message Zeph may start. The Check-ins service reads each description to choose one, or to skip. Users see the names, read-only.

Changes apply to the next check-in after saving.
How the cards behave

The whole top row of a card opens and closes it. A folded card keeps its name, the start of its description and its count, so the list can be scanned without opening anything. Several cards can be open at once. A card with unsaved changes says so on its folded row and never loses its text when folded. Save, Discard and Remove always sit in the same place at the bottom of the open card.
