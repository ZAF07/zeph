# The directness setting also sets how Zeph asks

Status: accepted (the owner, 25 and 26 Nov 2026). Built: pattern pipeline issue 40.

A User sets how direct Zeph is: gentle, balanced or direct. It was only about the **Read**: how soon and how plainly Zeph says its view (decision 7 of the pattern pipeline grill). The Agenda never read it, so a gentle User and a direct one got the same questions, in the same order, at the same pace. A User who picks "direct" expects it to cover how Zeph asks too, and a gentle one deserves more room.

The setting now also sets how Zeph asks. It moves four things, all in code:

- **the order of Approaches**: gentle never gets "would it have gone differently if…"; direct gets it first;
- **the wait** after a try that got nothing (5, 3, 2 days);
- **the tries with nothing before an Exploration rests** (3, 4, 5);
- **the fewest replies between two Curiosities** (4, 3, 2).

The numbers are Admin-set, one per setting. The rules that protect a User stay the same for everyone: the spacing doubles after brush-offs, "drop it" rests an Exploration at once, nothing is asked while they are struggling, never two Conversations in a row, Zeph never names a state first, and the ready gate never reads the setting.

## Considered Options

- **Same order for everyone, only the wording follows directness.** Rejected: a gentle User still gets the same questions as a direct one.
- **Move only the first Approach and the wait; keep the rest and the pace fixed.** This was the suggested answer, so that "direct" could not become a licence to interrogate. The owner chose to move both as well: a direct User asked for more, and the backing-off rules still hold.
- **Let the setting loosen the backing-off rules too.** Rejected: those are what stop asking from turning into pressure.

## Consequences

- The fewest replies between Curiosities covers every Curiosity, so a direct User also gets look-backs and Prediction follow-ups closer together.
- A direct User can be asked about one Pattern more often and for longer before Zeph gives up. Brush-offs still slow it down and "drop it" still ends it.
- Three settings became nine. Balanced keeps the old keys, so nothing changes for a User who never touched the setting.
- The Account page and the chat tool say the setting covers asking, so Users know what they choose.
